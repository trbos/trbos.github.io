# Upstream attribution

This player contains Web Dashers, a fan-made Geometry Dash web demo/mod by
the Web Dashers contributors. The original game/art attribution to RobTop
Games and the original in-game credits are preserved.

Source: https://github.com/web-dashers/web-dashers.github.io

Pinned revision: `84b123b20bca82066350fefe8b49849a24da701c`.

The original README is retained as `UPSTREAM-README.md`. The supplied
snapshot did not contain a repository LICENSE file; this notice does not
create a new license grant. Existing third-party notices in the Phaser and
Pako library files are unchanged.

Local adaptations are listed in `UPSTREAM.json`. The six WAV fallback files
are PCM16 decodes of the corresponding upstream Ogg effects, generated with
the browser's audio decoder. Gameplay physics, level data, natural deaths,
retry behavior, score/progress calculations and editor code are unchanged.
