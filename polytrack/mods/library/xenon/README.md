# Xenon

## About
Xenon is a mod for the Browser game PolyTrack by Kodub. It uses PolyModLoader
Xenon provides an API for mods to easily access the game's webGL renderer
<sub><sub>the name is definitely not inspired by a specific minecraft mod</sub></sub>
## Installation
For a guide on how to install mods for PolyModLoader, refer to [the PolyModLoader wiki](https://codeberg.org/polytrackmods/PolyModLoader/wiki/For-Users#interface)
The import link for this mod is
`https://cdn.polymodloader.com/cb/CRJakob/Xenon/main`
