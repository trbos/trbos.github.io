# PolyProcessing

## About
PolyProcessing is a mod for the Browser game PolyTrack by Kodub using PolyModLoader.

## Dependencies
Version 3.0.0 and onward require [the Xenon library mod](https://codeberg.org/CRJakob/Xenon).  
Version 5.0.0 also requires [Polymgui](https://codeberg.org/GameBuilder202/Polymgui/src/branch/dev).

## Installation
For a guide on how to install mods for PolyModLoader, refer to [the PolyModLoader wiki](https://codeberg.org/polytrackmods/PolyModLoader/wiki/For-Users#interface)  
The import link for this mod is  
`https://cdn.polymodloader.com/cb/CRJakob/PolyProcessing/main`
